# Datasets (not committed)

Put downloaded scam/phishing datasets in this folder. Everything here except this file is gitignored
because dataset licenses vary and some messages may contain real phone numbers or links.

Candidates:
- Smishtank: ~1,000 real US phishing texts (smishtank.com/dataset). Check its terms before reuse.
- SpaPhish: Spanish phishing and legitimate emails, CC BY 4.0 (data.mendeley.com/datasets/hz2d6gz7pc).
- UCI SMS Spam Collection: older English SMS spam/ham (archive.ics.uci.edu/dataset/228).
